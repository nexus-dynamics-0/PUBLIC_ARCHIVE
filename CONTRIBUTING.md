# Contributing to the GitHub Treasure Hunt

Welcome, Investigator.

Your objective is to explore the repository and uncover the **hidden phrase, objective password, or answer** required to proceed.

### Protocol 01 — Find the Answer

Investigate the files and repository artifacts to discover the required answer. It may be hidden in unexpected places.

### Protocol 02 — Encrypt It

Once you find the answer, encrypt it using the [CCTF Encryption Terminal](https://foss-hunt.vercel.app/encrypt).

### Protocol 03 — Submit Your Answer

Create a Pull Request with the **encrypted string only** in `answer.txt`.

- Do not submit the answer in plain text.
- Copy the encrypted string exactly as generated.
- Do not modify unrelated files.

**Important:** Pull Requests containing unencrypted answers will not be considered.

**Investigate. Encrypt. Submit.**
