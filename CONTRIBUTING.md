# Contributing to Github Treasure Hunt

Welcome, Investigator.

This repository contains information relevant to the ongoing investigation. However, not all information can be shared in plain text. To maintain the integrity of the investigation and prevent unauthorized access to sensitive information, **all communication submitted through Pull Requests (PRs) must be encrypted.**

## Protocol 01 — Discover the Password

Before submitting a Pull Request, investigate the repository and uncover the password required to proceed.

Look carefully through the available files,and other repository artifacts. Some information may be intentionally concealed.

Do not proceed until you have discovered the correct password.

## Protocol 02 — Encrypt Your Message

Once you have recovered the password, navigate to the authorized encryption terminal:

**[CCTF — Encryption Terminal](https://foss-hunt.vercel.app/encrypt)**

Use the terminal to encrypt your recovered password or the required message according to the instructions provided there.

Ensure that you copy the complete encrypted output. Even a minor alteration may render the message unreadable.

## Protocol 03 — Submit Your Pull Request

Create a Pull Request containing **only the encrypted string** in the designated location or submission field.

- Do not expose the recovered password in plain text.
- Do not include unencrypted hints or explanations that reveal the answer.
- Do not modify unrelated files.
- Ensure that the encrypted string is copied exactly as generated by the encryption terminal.
- A file named `answer.txt` must be created, and the required encrypted content/data must be placed inside this `answer.txt` file.

Your submission will be reviewed by the investigation team. If the message is valid, you will receive further instructions.

## Security Notice

Unencrypted communication may compromise the investigation and expose restricted information to unauthorized individuals.

**Discover. Encrypt. Submit. Proceed.**

Every artifact leaves a trail. Make sure yours does not reveal more than it should.
